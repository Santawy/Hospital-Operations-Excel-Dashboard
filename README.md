# Hospital-Operations-Excel-Dashboard# Hospital Operations Dashboard (Excel)

Excel analysis of 16,362 patient visits (Jan 2023 – Jun 2026) at HealthPlus Medical Center.

## What's inside
- **Data** – visit-level data: branch, department, treatment, doctor, wait time, billing, satisfaction, follow-up and 30-day readmission
- **Analysis** – formula summaries (COUNTIFS / AVERAGEIFS on a structured table)
- **Pivot Table** – PivotTables by branch, department, doctor and more
- **Page 1–3 analysis** – dashboard pages: overview & branches, departments / doctors / patients, trends & correlations

## Tools
Excel · PivotTables · Slicers · Charts · Structured references
